# Staging فقط — لم يُنشر شيء

الاسم المقترح gaminghub-duel-wss على Render بخطة free فقط. عنوان onrender.com تعيّنه Render بعد إنشاء الخدمة الموافق عليه. لم يُحجز الاسم؛ توفره غير متحقق. أداة Render لم ترجع الخدمات لعدم تحديد مساحة عمل مؤكدة. عُرضت My Workspace ولم أخترها أو أعدلها.

render.staging.yaml ملف منفصل اجتاز JSON Schema الرسمي. ملف render.yaml الأصلي محفوظ. النشر التلقائي والمعاينات off؛ لا قاعدة أو قرص أو خدمة مدفوعة. تحقق منصة Render/CLI والبناء السحابي غير منفذين.

## الموافقة المطلوبة لاحقًا

1. تأكيد مساحة Render الصحيحة، ثم فحص الخدمات قبل أي إنشاء. إذا كان الاسم موجودًا، لا تطبق Blueprint عليه ولا تستبدله؛ توقف لتحديد اسم خدمة Staging جديدة.
2. السماح برفع التزام التسليم إلى integration/gaminghub-final-20261024 فقط، بعد مراجعة منع Actions. لم يحدث push هنا. الملفات المحلية لا تصل إلى Render تلقائيًا.
3. الموافقة على إنشاء خدمة web جديدة مجانية واحدة بهذا الملف وأول نشر يدوي لها فقط، دون تعديل الإنتاج أو main أو مشروع آخر، ودون ترقية مدفوعة. إنشاء الخدمة قد يبدأ نشرًا أوليًا حتى مع إيقاف النشر التلقائي؛ لذلك لا تنشئها قبل الموافقة.
4. بعد معرفة العنوان الفعلي، تحقق من الهوية وTLS وHealth Check والمصادقة وسجلات المنصة. بعدها عيّن endpoint وverified_host وavailability_verified وenabled في data/duel_service.json. العنوان المفترض gaminghub-duel-wss.onrender.com غير مفعل أو مفترض التوفر.
5. اختبر WSS وAndroid قبل Internet PASS أو Google Play. مورد العنوان مضمن في التطبيق، لذا تفعيله يحتاج تصديرًا بعد الموافقة؛ APK الحالي لا يوصف بتشغيل الإنترنت المكتمل.

## إعداد الخدمة

TLS/WSS ينتهي عند Render edge. الخدمة تستمع على 0.0.0.0:$PORT داخل Render فقط؛ محليًا loopback. /health يعيد 200 بعد تحميل الكتالوج وفتح مخزن البلاغات.

/session يصدر جلسة ضيف موقعة HMAC بعد إعلان قبول القواعد، لمدة ست ساعات وحد إصدار. WebSocket يتطلب Bearer؛ DUEL_AUTH_SECRET ينشأ على Render عند الإنشاء الموافق عليه ولا يُضمّن في APK أو Git. هذه مصادقة جلسة ضيف وليست حساب مستخدم موثقًا.

الاستعادة مقيدة بهوية الجلسة ورمز غرفة يدور عند الاستعادة. الغرف في الذاكرة وتضيع عند إعادة تشغيل الخدمة. توجد حدود IP لإصدار الجلسات والترقية وحدود اتصال للطلبات والدردشة والصوت. رفض Origin مخصص للعملاء الأصليين؛ لا يُدّعى اختبار اختراق منشور.

الإغلاق يلغي مهام الخلفية ويغلق الاتصالات. الخطة المجانية قد تنام؛ مهلة مصادقة العميل 65 ثانية. أداء الصوت الجماعي على Render free غير متحقق.

## حدود تمنع اعتبارها إنتاجًا عامًا

SQLite البلاغات والحظر في /tmp مؤقت وقد يضيع عند النشر/إعادة التشغيل. يلزم تخزين دائم وآلية مراجعة معتمدان قبل UGC عام. لا تُفعّل قاعدة أو خطة مدفوعة دون موافقة منفصلة. الضيوف يستطيعون إنشاء هوية جديدة؛ الحظر ليس تحقق حساب دائمًا أو ضمانًا ضد العودة المسيئة.

خادم الخدمة الجديدة يمزج PCM إلى تدفق واحد لكل مستقبل، مستعملًا واجهة الصوت الأصلية دون استبدالها. خوادم الصوت الإنتاجية لم تتغير. نقل PCM ليس دليلًا على صوت ستة هواتف أو AEC فعليًا.
