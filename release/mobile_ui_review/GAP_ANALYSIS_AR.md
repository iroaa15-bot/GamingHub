# فجوات الشاشات قبل استكمال الواجهة

المرجع هو APK 2b048ed المثبت وصور اختبار CPH2015، وليس صور التصميم المرفقة. مسودة UI المحلية السابقة لم تُقبل أو تُصدّر بعد.

| الشاشة | الموجود فعليًا | الفجوة/التصرف المطلوب |
|---|---|---|
| الرئيسية | شعار Gaming Hub الأصلي، قائمة الألعاب، مداخل الغرف، تقدم محلي | مساحة شعار وبطاقات أكبر من اللازم؛ تقليل العرض لا استبدال الشعار |
| مكتبة الألعاب | الألعاب العشر في main.gd | عمود واحد على هاتف 420 وحدة وصور 150 وحدة؛ صفوف أقصر وشبكة متجاوبة مع استثناء تكبير القراءة |
| غرفة كلاسيكية | إنشاء/انضمام/مطابقة إنتاجية، زر صوت اختياري | عناصر رأسية طويلة؛ حفظ البروتوكول والتمييز عن الخدمة الجديدة |
| غرفة 2–6 | إعدادات مؤقت/نقاط وعدد، دردشة/أسئلة/تأكيد/صوت في نفس العمود | إخفاء أدوات المباراة قبل البدء، تقسيم الإعدادات/الدردشة/الأسئلة/الإبلاغ إلى أقسام واضحة؛ عدم إظهار لاعب0 أو نقاط[] |
| أثناء اللعب | صور الخصوم والأسئلة ونعم/لا والتخمين والدور والنقاط | صلاحية اللعب عبر الإنترنت BLOCKED إلى نشر WSS المعتمد؛ لا إضافة لاعبين أو نتائج وهمية لمشابهة المرجع |
| التحكم باللمس | ScrollContainer أصلي | بعض الزخارف/الأزرار تستهلك الحدث؛ تمرير أحداث القوائم للتمرير الأصلي وإبقاء الحقول والتفاعلات المخصصة محمية |
| الرجوع | معالجات خاصة وauto-quit افتراضي | إصلاح مستقل في cf93bb9؛ ثبت على هاتف باستخدام ملفات تشخيص، مطلوب APK acceptance |
| إعدادات القراءة واللغة | عربية/إنجليزية وتكبير قراءة | الحفاظ عليها؛ عمود واحد عند تكبير القراءة وأهداف لمس >=56 وحدة |
| الحساب والأصدقاء | تقدم محلي ومشاركة غرفة؛ لا إثبات حسابات OAuth/ربط أصدقاء كاملة | ليس جزءًا من تعديل UI الحالي؛ يحتاج فحص وتكامل مصادقة حقيقية وأذونات/إعدادات معتمدة |
| Admin | لا dashboard منشور مثبت | مؤجل حتى تبعيات المراحل السابقة؛ لا زر إدارة شكلي أو مقاييس مختلقة |
| صور المشاهير المرجعية | ليست من المكتبة المعتمدة في هذا العمل | لا استيراد أو توليد صور جديدة؛ الأصل200 محفوظ |

المرحلة الحالية: إصلاحات رجوع محدودة تم التحقق من مصدرها على الهاتف، ثم مراجعة UI المحلية. لا نشر، ولا أنظمة حسابات جديدة، ولا تعديل السيرفرات أو محرك الصوت. أي PASS للواجهة لا يعني PASS للشبكة أو الميكروفون أو جاهزية الإصدار الكامل.
