# إصلاح تحقق كود الغرفة

السبب المؤكد: الخادم المحلي يولد6أرقام، بينما _request_room_action في photo_duel_extension_ui.gd يستخدم ^[A-F0-9]{8}$؛ لقطة Android تظهر رفض176030 وطلب8خانات. آخر محاولة تعديل قبل حد الاستخدام لم تنفذ؛ تم التحقق من المصدر قبل الإصلاح.

الإصلاح: room_invite_code.gd يطبع الأرقام العربية والفارسية إلىASCII ويزيل فواصل النسخ والمسافات. مسار الغرف المشتركة يقبل6أرقام أو8HEXقديمة؛ كلاسيكي6أحرف/أرقام يحتفظ بتوافقه. الواجهة والعميل وكلاسيكي الانضمام تستخدم المصدر نفسه. لا تغيير لأي سيرفر.

PASS Godot مستهدف: قبول/رفض صيغ الحدود والتوافق القديم، وتحميل الكلاسيكي، وإنشاء غرفة رقمية والانضمام إليها من واجهتيGodot حقيقيتين عبرWebSocketمحلي8886 بكود مكتوب بالأرقام العربية؛ كلاالعميلين دخلا نفس الغرفة. لا تكرار اختبارات2/3/6القديمة.
Android للمصدر المصحح: بانتظار بناء وتثبيت واختبار موثق؛ لاPASSمسبق.

التصميم: توضيح المستخدم الأخير يعيد المرجع كهدف مطابقة نهائية، مع الحفاظ على الأصول والوظائف وعدم اختلاق أشخاص أو أرصدة. التحسينات السابقة محفوظة؛ المطابقة الكاملة غير مكتملة.
