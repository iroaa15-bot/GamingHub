# محولات الكتابة والهوية والترتيب
أضيفت مسارات أصلية للألعاب 2 و7 و9، دون تحويل الكتابة أو ترتيب الخطوات إلى اختيار متعدد. الإجابات المقبولة بالعربية والإنجليزية والتركية يتحقق منها الخادم. أدلة الهوية تدريجية خاصة بكل لاعب، وتخفض نقاطه. ترتيب الخطوات يُخلط مع بقاء ترتيب الإجابة سريًا، وتدعم الواجهة التراجع والتأكيد.
PASS: python tests/shared_original_mechanics.py — ثلاثة مسارات أصلية ببيانات الكتالوج، رفض مدخلات غير صالحة/مكررة، سرية الإجابة، أدلة خاصة، نقاط صحيحة 1500/0 و1300/0 و1500/0.
PASS: Godot tests/shared_mechanics_ui.gd — تحميل وإنشاء الواجهات الثلاث فعليًا. تحذير موارد عند انتهاء أداة الاختبار محفوظ؛ ليس اختبار استقرار Android.
هذه اختبارات خادم ووصلات واجهة محلية؛ اختبار النقل الحقيقي لهذه المحولات واختبار Android لم ينفذا بعد. لا APK جديد، لا تغيير إنتاج، لا حذف عمل سابق. بقية المحولات قيد التنفيذ.
