# المرحلة الأولى — المحولات الأصلية المتبقية

الألعاب 2 و7 و9: كتابة، هوية بأدلة خاصة وتخفيض النقاط، ترتيب خطوات مع التراجع. الألعاب 4 و5 و8: مغامرة بتسلسل المراحل والنصوص الأصلية، معلومات عامة بصورها الأصلية، ذاكرة بقلب الأزواج والمحاولات. جميعها تستخدم إنشاء/انضمام واتفاق وحضور وخدمات صوت ودردشة الغرف الموجودة. اللعب الفردي لم يتغير.

PASS: اختبارات Python للمسارات الأصلية والحدود وسرية الإجابة واللغات الثلاث. اختبار الذاكرة يتضمن إعادة الاتصال، رفض ادعاء اكتمال اللوحة، استقلال الكشف لكل لاعب، حساب النقاط الأصلي (88 مقابل90)، وأزمنة الكشف الأصلية.
PASS: Godot 4.5.1 عميلان حقيقيان عبر WebSocket محلي8889 وواجهات shared_quiz_ui. إنشاء وانضمام واتفاق، السؤال المشترك، callbacks الفعلية لكل نمط، ونتائج ونقاط متطابقة. أول تشغيل نجحت فيه2/7/4/5؛ إعادة9 نجحت بعد تحديث أزرار الترتيب وانتظار إطارات الواجهة في الاختبار. إعادة8 نجحت بعد معالجة أنواع الأرقام الشبكية، وحُلّت اللوحة بقلب الصور وتذكرها دون كشف بيانات الخادم السرية.
الدليل: first-run.log وordering-pass-memory-diagnostic.log وmemory-pass.log وscreens/*.png. الفشل الأول محفوظ، وليس PASS شاملًا لنفس التشغيل. التحذير المحلي بعدم إنشاء shader cache لا يمنع الرسم؛ لا يُعد دليل استقرار Android.
تمت مواءمة مدة كشف الذاكرة ونقاطها الأصلية بعد اختبار النقل؛ تحقق الحساب والمدة باختبار الخادم المستهدف. لم تُكرر اختبارات السينما والصوت السابقة.

لا تزال اختبارات Android لهذه الإضافات معلقة عند هذا الحفظ. الخادم محلي فقط؛ اللعب العام يحتاج نشر خدمة منفصلة بموافقة، ولم يُنشر شيء. لا حسابات أو إدارة جديدة؛ المرحلة2 لم تكتمل. صور اللوحات توضح الوظائف ولا تعني اعتماد التطابق البصري النهائي.
